# Imperfecto vs. indefinido · ELE con Paula

Sitio educativo en español para estudiantes lusoparlantes A2–B1. Funciona sin instalar dependencias ni compilar.

## Abrir en tu computador

Descomprime la carpeta y abre `index.html` en tu navegador. Mantén todos los archivos juntos para que funcionen el audio y el PDF.

## Subir a GitHub

1. Crea un repositorio o abre el que quieras utilizar.
2. Sube el contenido de esta carpeta a la raíz del repositorio. `index.html` debe quedar en la raíz, no dentro de otra carpeta.
3. Confirma la subida de los archivos.
4. Para publicarlo con GitHub Pages, configura la publicación desde la rama que contiene los archivos y desde su carpeta raíz.
5. Abre la dirección que GitHub Pages muestre cuando termine la publicación.

No subas el ZIP como único archivo: primero descomprímelo y sube los archivos de su interior.

## Archivos

- `index.html`: estructura y estilos.
- `app.js`: actividades, traducciones e interacciones.
- `audio.mp3`: audio aportado por la profesora.
- `material.pdf`: PDF aportado por la profesora, optimizado para la web.
- `.nojekyll`: permite servir el sitio como archivos estáticos.
- `.gitignore`: excluye archivos temporales habituales.

## Actividades

Comparación de usos; seis diapositivas de gramática; conjugaciones de once verbos; dieciocho tarjetas de conversación; seis situaciones en pareja; historias al azar; comprensión auditiva con transcripción; producción escrita final.

Incluye traducciones al portugués por cursor, teclado o toque; tamaño de letra ajustable; pantalla completa; guardado local de notas y progreso; exportación e importación de progreso.

## Guardado

El progreso se guarda únicamente en el navegador y dispositivo utilizados. No se sincroniza entre personas ni entre la versión local y una dirección web. Usa Exportar e Importar para trasladarlo.

## Material de referencia

PDF y audio: ELETUTOR, Clase 11, A2, aportados por la profesora. Se mantienen sus atribuciones. Las actividades complementarias se prepararon para ELE con Paula. Este repositorio no otorga una licencia adicional sobre el PDF o el audio.
